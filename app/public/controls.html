wheelzoom (cursor-anchored)
click nodeselect it & set dependency "from"
alt+click nodequeue it as a dependency target (chip in the right pane); alt+click again to remove it; without changing selection

shift+drag nodemove it; pins & saves position on release
ctrl+shift+click nodeadd/remove it from a multi-select group
ctrl+shift+drag a selected nodemove the whole multi-select group together
ctrl+alt+drag backgroundbox-select — any node the box touches joins the multi-select group
click empty backgroundclear selection (single & multi-select)
click a dependency lineselect it for editing
drag a control-point handlereshape the selected dependency's curve; saves on release
drag an anchor handle (dashed ring)slide where the line/arrowhead touches that node's box, around its perimeter; saves on release

export / import

export dropdown - pngcurrent viewport rasterized to a print-ready 600 DPI, 17x11in (landscape) PNG
export dropdown - csvnode names + dependencies, reporting format only
project dropdownexport/import — full round trip, position/pin state/dependencies included; delete all wipes every node & dependency (confirmation prompt)
annotate
draw annotations dropdownpick Group Label, Text Box, Draw Circle, Draw Arrow, Database, or Server, arms the tool (crosshair cursor) - drag a rectangle (oval for Draw Circle, line for Draw Arrow) on the canvas, then set its color (and note, for the first two)
group labelnote is drawn above the box
text boxnote is centered inside the box and clipped to it - only visible within the drawn outline
draw circlean oval outline with no note - color only
draw arrowa line from the drag's top-left to bottom-right with an arrowhead, no note - color only
database / serverfixed icon inscribed in the box, colored to match, no note and no outline - click anywhere in the box to edit
click an annotation's outline or note textedit its color (and note, if it has one) - the dialog's own delete button removes it (confirmation prompt)

hide colors dropdowncheck a swatch to hide every node, annotation, and dependency using that exact color - stays open across multiple checks, click elsewhere to close
